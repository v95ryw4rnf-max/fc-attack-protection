# FC Attack Protection

A RuneLite plugin that helps prevent accidentally attacking players who are members of your current Friends Chat.

## Features

- Blocks Attack actions against Friends Chat members.
- Allows attacks against players who are not Friends Chat members.
- Can be enabled or disabled in the plugin configuration.
- Displays a chat message when an attack is blocked.

## Configuration

The plugin includes one setting:

- **Enable protection** — turns attack protection on or off.

## Requirements

- RuneLite
- Java 11

## Building

To build the project, run:

    .\gradlew.bat build
